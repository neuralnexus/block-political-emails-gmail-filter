# Block most political emails. Enjoy the peace.

Sends political fundraising, charity appeals, petitions, and action requests directly to **Trash** upon receipt. 
Works with Gmail or Google Workspace. 
You need a desktop computer for the setup process. 

## Add it in 3 steps

1. **Download:** [Click here to download the filter](https://github.com/neuralnexus/block-political-emails-gmail-filter/releases/latest/download/political-filter.xml).
2. **Open Gmail:** Click **⚙️ → See all settings → Filters and Blocked Addresses → Import filters**.
3. **Add it:** Click **Choose File**, pick the downloaded file, then **Open file → All → Create filters**. Done!

Want to clean up old mail too? 
Before **Create filters**, check **Apply new filters to existing email**.

**Broad by design:** charity newsletters with donation requests can be caught too. Common receipts and payment confirmations are excluded. No filter catches everything. Gmail permanently removes Trash after 30 days.

Changed your mind? On the same settings page, you can just delete the seven filters. Move any wanted messages out of Trash before they are deleted permanently.
